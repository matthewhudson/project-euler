# Project Euler

My solutions to [Project Euler](https://projecteuler.net/) problems in Python 3.

This is a learning project — exploring interesting math concepts and practicing Python techniques. Project Euler problems are designed so that brute-force approaches are impossibly slow; solving them requires finding clever mathematical or algorithmic insights.

## Usage

Each file is a standalone script:

```bash
python3 euler1.py
```

## Solutions

| File | Problem |
|------|---------|
| `euler1.py` | Multiples of 3 or 5 |
| `euler2.py` | Even Fibonacci numbers |
| `euler3.py` | Largest prime factor |
| `euler4.py` | Largest palindrome product |
| `euler5.py` | Smallest multiple |
| `euler6.py` | Sum square difference |
| `euler7.py` | 10001st prime |
| `euler8.py` | Largest product in a series |
| `euler9.py` | Special Pythagorean triplet |
| `euler10.py` | Summation of primes |
| `euler11.py` | Largest product in a grid |
